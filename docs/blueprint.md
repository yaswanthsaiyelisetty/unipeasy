# **App Name**: Project Ascend

## Core Features:

- AI-Powered Interactive Learning Assistant: Generates simple explanations as a story with visuals and real-life analogies. Includes a quick adaptive quiz and AI-generated interactive mind map. Saved mindmaps will be added to user's Memory Palace
- AI Exam Strategist: Generates personalized, prioritized study plans based on syllabus, timeframe, learning pace, and past exam papers, to maximize student's exam score in a limited time. Output is a prioritized Pomodoro-based timetable.
- AI Skill Accelerator: Skill training through structured levels, each with AI feedback and adaptive progression. Trains both technical and soft skills.
- Onboarding and Profile Setup: User onboarding and profile setup, to capture details like university and branch, which will be used to enhance and personalize later AI features.
- Personalized Dashboard: A dashboard summarizing the user's progress, with direct access to core features, and a quick view of upcoming study blocks.
- Memory Palace: A personal library for storing mind maps, images, and quiz results for quick revision.
- AI Feedback Tool: Provides the user feedback after each training module.

## Style Guidelines:

- Primary color: Deep sky blue (#3399FF) to signify intelligence, trust, and focus.
- Background color: Light gray (#F0F4F7), provides a clean and distraction-free backdrop to focus attention
- Accent color: Orange (#FF8C33) to highlight CTAs, and emphasize important details
- Headline font: 'Space Grotesk', a sans-serif font, with a modern, somewhat technical and engaging feel; body text: 'Inter' for longer text blocks
- Code font: 'Source Code Pro' for displaying code snippets.
- Use a consistent set of simple icons throughout the platform
- Clean, well-organized layouts that focus attention
